## Схема підключення

### Реле (активно-високі — HIGH = ввімкнено)

| Пін плати | GPIO | RELAY# | Функція               | Arduino-назва |
|-----------|------|--------|-----------------------|---------------|
| PE8       | 75   | RELAY1 | Реле батареї          | ReleBtr       |
| PE7       | 74   | RELAY2 | Селектор ходу вперед/назад | ReleSlc  |
| PB2       | 73   | RELAY3 | Гідравлічний насос    | RelePump      |
| PB1       | 72   | RELAY4 | Лівий клапан тиску    | ReleLPV       |
| PB0       | 71   | RELAY5 | Правий клапан тиску   | ReleRPV       |
| PD12      | 59   | RELAY6 | Лівий клапан скидання / підняти кузов | ReleLRV  |
| PD13      | 60   | RELAY7 | Правий клапан скидання / опустити кузов | ReleRRV |
| PD15      | 62   | RELAY8 | Перемикач гідравліки на кузов | ReleSsvl      |

> PD12/PD13/PD15 були PWM-виходами. Перероблені під GPIO-реле. Залишилось PWM 1-8 (PA0-PA3, PE10-PE13) і PWM 10 (PD14).

### Вихід на регулятор мотора

| Пін  | Функція | Параметр |
|------|---------|----------|
| PA0  | PWM 1000-2000 мкс | SERVO1_FUNCTION=94 |

Регулятор мотора повинен приймати стандартний RC PWM (1000-2000 мкс, 50 Гц).

## Канали керування і логіка роботи

> Скрипт читає RC-канали напряму через `rc:get_pwm(n)` — параметри `RCMAP_*` ArduPilot не впливають.
> Якщо на пульті SIYI канали призначені інакше — змініть константи `CH_VERT`, `CH_HORT` тощо на початку `JRVS_MamontUGV.lua`.

### CH1 — Газ та гальмо (правий стік вертикально)

```
1500-2000 мкс → ГАЗ ВПЕРЕД
  Вихід на мотор: 1000 + (CH1-1500)/500 × kGear × 1000 мкс
  kGear = 0.20/0.35/0.60 залежно від передачі
  Гальма повністю відпускаються

1000-1400 мкс → ГАЛЬМО
  Мотор: 1000 мкс (зупинено)
  Гідравліка: насос ON + клапани тиску ON + клапани скидання OFF

~1500 мкс → НЕЙТРАЛЬ (вільний хід)
```

**Чому нижня межа 1000, а не 600?**
`rc:get_pwm()` в ArduPilot після калібрування завжди повертає значення в діапазоні **1000-2000 мкс**. Значення 600 мкс з оригінального Arduino-коду виникало через особливості `pulseIn()` і відсутність калібрування. Тут така межа не потрібна.

### CH2 — Розворот (правий стік горизонтально)

Активний тільки коли CH1 в нейтралі (ні газ, ні гальмо):

```
1000-1380 мкс → ПОВОРОТ ВЛІВО
  Гальмо лівої сторони + газ пропорційно відхиленню

1600-2000 мкс → ПОВОРОТ ВПРАВО
  Гальмо правої сторони + газ пропорційно відхиленню

1400-1600 мкс → ЦЕНТР → вільний хід, гальма відпускаються
```

При переході між лівим і правим поворотом — протилежна сторона автоматично звільняється без проміжного центрування.

### CH3 — Реле батареї (перемикач)

```
>1100 мкс (тримати ≥1 с) → RELAY1 ON  → батарея підключена
<1100 мкс (будь-який момент) → RELAY1 OFF → батарея від'єднана
```

Затримка 1 с — захист від випадкового спрацювання.

### CH4 — Передачі (перемикач 2-3 позиції або тумблер)

```
Кожне перетинання порогу 1200 мкс (в будь-який бік) = перемикання передачі

Передача 1 (понижена):  kGear = 0.20 → макс швидкість ~20% від повного газу
Передача 2 (середня):   kGear = 0.35 → макс ~35%
Передача 3 (підвищена): kGear = 0.60 → макс ~60%
```

Логіка "будь-який перетин порогу" зроблена щоб працювало з тумблером двох позицій — кожне клацання = наступна передача.

### CH5 — Селектор ходу вперед/назад (перемикач)

```
>1100 мкс (тримати ≥1 с) → RELAY2 ON  → хід вперед (або назад — залежить від механіки)
<1100 мкс (будь-який момент) → RELAY2 OFF → протилежний хід
```

Та ж затримка 1 с що і у батареї. **Рекомендація:** перемикати тільки при нульовому газі — апаратного блокування немає.

### CH6 — Кузов самоскида

```
>1600 мкс → ПІДНЯТИ
  ReleSsvl ON — гідравліка переключена на кузов
  RelePump ON — насос працює
  ReleLRV  ON — клапан подачі тиску в циліндр → кузов іде вгору
  ReleRRV OFF — клапан скидання закрито

<1400 мкс → ОПУСТИТИ
  ReleSsvl ON — гідравліка переключена на кузов
  RelePump ON — насос працює
  ReleLRV OFF — клапан подачі закрито
  ReleRRV  ON — клапан скидання → тиск виходить → кузов іде вниз

1400-1600 мкс → СТОП (кузов тримається на місці, все OFF)
```

**Блокування:** логіка кузова активна тільки при нульовому газі. При русі або гальмуванні CH6 ігнорується, гідравліка переходить у режим гальм.

**Чому LRV/RRV мають подвійну роль:** `ReleSsvl` (RELAY8) фізично перемикає гідравлічний контур. Коли він OFF — LRV/RRV керують гальмівними циліндрами. Коли ON — той самий насос і ті самі клапани керують циліндром кузова.

### Гідравліка гальм детально

```
Момент натискання гальма (CH1 < 1400):
  RelePump  ON  — насос запускається
  ReleLPV   ON  — лівий клапан тиску відкривається (тиск росте)
  ReleRPV   ON  — правий клапан тиску відкривається
  ReleLRV   OFF — лівий клапан скидання закрито (тиск утримується → гальмо)
  ReleRRV   OFF — правий клапан скидання закрито

Через 350 мс — антизаклинювальна пульсація:
  ┌── 400 мс: LRV/RRV відкриваються (тиск скидається, гальмо слабшає)
  └──  80 мс: LRV/RRV закриваються (тиск повертається, гальмо повне)
  └── 400 мс: ...повтор

Відпускання гальма (CH1 > 1500):
  LRV/RRV  ON  — клапани скидання відкриті (тиск скинуто)
  Pump/LPV/RPV OFF — насос і клапани тиску вимкнені
```

## Збірка прошивки

Скрипт `JRVS_MamontUGV.lua` вбудовується в ROMFS прошивки автоматично — **SD-карта не потрібна**.

```bash
cd /path/to/ardupilot
./waf configure --board JarvisH743
./waf rover
# → build/JarvisH743/bin/ardurover.apj
```

ArduPilot при старті автоматично завантажує всі `.lua` з ROMFS.
