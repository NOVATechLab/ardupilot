# JarvisH743 — Mamont V2

Прошивка ArduRover для плати JarvisH743 (STM32H743) з Lua-скриптом керування
амфібійним гідравлічним ровером «JRVS Mamont UGV».

Версія скрипту: V2 (амфібія: суходіл / комбі / плавання, 16 реле).

## Схема підключення

### Реле (активно-високі — HIGH = ввімкнено)

| Пін плати    | GPIO | RELAY# | Функція | Lua idx |
|--------------|------|--------|---------|---------|
| PE8 (RELAY1) | 75 | RELAY1  | Реле батареї (ReleBtr)           | 0  |
| PE7 (RELAY2) | 74 | RELAY2  | Селектор вперед/назад (ReleSlc)  | 1  |
| PB2 (RELAY3) | 73 | RELAY3  | Гідронасос (RelePump)            | 2  |
| PB1 (RELAY4) | 72 | RELAY4  | Лівий клапан тиску (ReleLPV)     | 3  |
| PB0 (RELAY5) | 71 | RELAY5  | Правий клапан тиску (ReleRPV)    | 4  |
| PD12 (PWM9)  | 59 | RELAY6  | Лівий гвинт — ВПЕРЕД             | 5  |
| PD13 (PWM10) | 60 | RELAY7  | Лівий гвинт — НАЗАД              | 6  |
| PD15 (PWM12) | 62 | RELAY8  | Правий гвинт — ВПЕРЕД            | 7  |
| PA1 (PWM2)   | 52 | RELAY9  | Правий гвинт — НАЗАД             | 8  |
| PA2 (PWM3)   | 53 | RELAY10 | Кузов — ПІДНЯТИ                  | 9  |
| PA3 (PWM4)   | 54 | RELAY11 | Кузов — ОПУСТИТИ                 | 10 |
| PA8 (PWM5)   | 55 | RELAY12 | Відвал-ківш — ПІДНЯТИ            | 11 |
| PE11 (PWM6)  | 56 | RELAY13 | Відвал-ківш — ОПУСТИТИ           | 12 |
| PE14 (PWM7)  | 57 | RELAY14 | Світло                          | 13 |
| PE13 (PWM8)  | 58 | RELAY15 | Резерв — ПІДНЯТИ / +            | 14 |
| PD14 (PWM10) | 61 | RELAY16 | Резерв — ОПУСТИТИ / –           | 15 |

> **V2-зміни в залізі.** PA1-PA3, PA8, PE11, PE13, PE14, PD14 переведені з PWM у GPIO-реле
> (`define AP_RELAY_NUM_RELAYS 16`). Це ліміт ArduPilot (рівно 16). Після цього
> з PWM лишається тільки **PA0** (газ, SERVO1). Вільних PWM-виходів більше немає.
>
> **Зміна гідравліки гальм.** У V1 PD12/PD13/PD15 були клапанами скидання (LRV/RRV)
> і перемикачем контуру (SSVL). У V2 їх немає — антиблокувальна пульсація гальм
> робиться **пульсацією самих клапанів тиску LPV/RPV** (RELAY4/RELAY5).
> Кузов/відвал керуються власними реле, спільним з гальмами є лише насос (RELAY3).

### Вихід на регулятор мотора

| Пін | Функція | Параметр |
|-----|---------|----------|
| PA0 | PWM 1000-2000 мкс | SERVO1_FUNCTION=70 (Script1), MOT_PWM_TYPE=4 |

ArduPilot керує газом через стандартний алгоритм Rover. Скрипт лише обмежує хід
через `SERVO1_MAX` / `MOT_THR_MAX` залежно від передачі (CH4).

## Канали керування і логіка роботи

> Скрипт читає RC-канали напряму через `rc:get_pwm(n)` — `RCMAP_*` на службові канали не впливає.
> Якщо на пульті SIYI канали призначені інакше — змініть константи `CH_*` на початку
> `JRVS_MamontUGV.lua`.
>
> **CH3 і CH4 навмисно лишені вільними** (їх не читає скрипт), щоб не конфліктувати з
> типовими призначеннями каналів у QGroundControl. Батарея і передача перенесені на CH11/CH12.

| CH | Канал             | Функція |
|----|-------------------|---------|
| CH1 | правий стік верт. | газ / аварійне гальмо |
| CH2 | лівий стік гориз. | поворот (одностороннє гальмо / диф. гвинти) |
| CH3 | —                 | **вільний** (не використовується) |
| CH4 | —                 | **вільний** (не використовується) |
| CH5 | —                 | селектор вперед/реверс (>1700, утримати 1 с) |
| CH6 | 3-поз. SC         | режим: суходіл / комбі / плавання |
| CH7 | кнопка T2         | кузов підняти/опустити (RELAY10/11) |
| CH8 | кнопка T3         | відвал підняти/опустити (RELAY12/13) |
| CH9 | кнопка SD         | світло (RELAY14) |
| CH10 | кнопка T4         | резерв ± (RELAY15/16) |
| CH11 | —                 | реле батареї (>1700, утримати 1 с) |
| CH12 | 3-поз.            | передача G1/G2/G3 |

### CH1 — Газ та аварійне гальмо

```
>1510 мкс → ГАЗ      — ArduPilot керує газом у межах SERVO1_MAX / MOT_THR_MAX
1400-1510 → НЕЙТРАЛЬ
<1400 мкс → АВАРІЙНЕ ГАЛЬМО (обидві сторони) — насос ON + пульсація LPV/RPV
```

### CH2 — Поворот (дуговий)

```
<1380 мкс → ВЛІВО   — ліве гальмо ON (одностороннє, без пульсації)
>1620 мкс → ВПРАВО  — праве гальмо ON
1380-1620 → ЦЕНТР   — гальма відпущені
```

Аварійне гальмо CH1 має пріоритет над CH2.

### CH11 — Реле батареї

```
>1700 мкс (тримати ≥1 с) → RELAY1 ON
≤1700 мкс                → RELAY1 OFF
```

### CH12 — Передачі (3 позиції)

```
<1200 → G1   SERVO1_MAX=JRVS_G1_SVO  MOT_THR_MAX=JRVS_G1_THR
<1700 → G2   SERVO1_MAX=JRVS_G2_SVO  MOT_THR_MAX=JRVS_G2_THR
≥1700 → G3   SERVO1_MAX=JRVS_G3_SVO  MOT_THR_MAX=JRVS_G3_THR
```

### CH5 — Селектор вперед/реверс

```
>1700 мкс (тримати ≥1 с) → RELAY2 ON  → реверс
≤1700 мкс                → RELAY2 OFF → вперед
```

Рекомендація: перемикати тільки при нульовому газі — апаратного блокування немає.

### Гідравліка гальм (V2)

```
Натискання гальма (CH1 < 1400):
  RelePump ON, ReleLPV ON, ReleRPV ON  → тиск росте, гальмо

Через JRVS_BRK_HOLD мс — антиблокувальна пульсація самих клапанів тиску:
  ┌── JRVS_BRK_REL мс: LPV/RPV OFF (тиск скидається, гальмо слабшає)
  └── JRVS_BRK_PLS мс: LPV/RPV ON  (тиск повертається, гальмо повне)
  └── повтор

Відпускання (CH1 ≥ 1400, центр CH2):
  LPV/RPV OFF, RelePump OFF
```

### Допоміжні CH7-CH10 (працюють у будь-якому режимі / при будь-якому газі)

```
CH7  кузов :  >1700 RELAY10 (вгору) / <1300 RELAY11 (вниз) / центр — обидва OFF
CH8  відвал:  >1700 RELAY12 (вгору) / <1300 RELAY13 (вниз) / центр — обидва OFF
CH9  світло:  >1700 RELAY14 ON / інакше OFF
CH10 резерв:  >1700 RELAY15 (+)    / <1300 RELAY16 (–)    / центр — обидва OFF
```

Кузов/відвал/резерв вмикають спільний насос RELAY3 (один гідроконтур із гальмами).
Світло насос не вмикає. Пари UP/DOWN взаємно виключені.

## Режими руху (CH6)

```
<1200 мкс → LAND  (суходіл)
1200-1699 → COMBI (суходіл + гвинти одночасно)
≥1700 мкс → SWIM  (тільки плавання)
```

**LAND** — газ через ArduPilot, гідрогальма (CH1), одностороннє гальмо в повороті
(CH2). Гвинти OFF.

**SWIM** — CH1/CH2 не керують суходільним приводом; газ SERVO1 тримається в нейтралі
(SERVO1_TRIM), насос гвинтів вимкнений. Замість цього — гребні гвинти через реле,
напрямок враховує селектор CH5:

```
ГАЗ   (CH1 > 1510): обидва гвинти вперед   → RELAY6 + RELAY8
ГАЛЬМО(CH1 < 1400): обидва гвинти назад    → RELAY7 + RELAY9  (гальмування на плаву)
Поворот вліво  (CH2): RELAY7 + RELAY8   (лівий назад, правий вперед)
Поворот вправо (CH2): RELAY9 + RELAY6   (правий назад, лівий вперед)
Реверс (CH5)        : усе навпаки
```

Взаємне виключення FWD/REV кожного гвинта гарантоване (ніколи разом).

**COMBI** — одночасно виконуються LAND і SWIM: машина їде колесами/гусеницями і
крутить гвинтами.

При зміні режиму CH6 виходи попереднього режиму скидаються в безпечний стан
(гвинти OFF, гальма відпущені).

## Кастомні параметри JRVS_*

Скрипт реєструє власну таблицю параметрів (ключ 72). Видно в Mission Planner / MAVProxy.

| Параметр | Дефолт | Опис |
|----------|--------|------|
| JRVS_G1_SVO  | 1200 | SERVO1_MAX для G1 (мкс) |
| JRVS_G2_SVO  | 1350 | SERVO1_MAX для G2 (мкс) |
| JRVS_G3_SVO  | 1600 | SERVO1_MAX для G3 (мкс) |
| JRVS_G1_THR  | 20   | MOT_THR_MAX для G1 (%) |
| JRVS_G2_THR  | 35   | MOT_THR_MAX для G2 (%) |
| JRVS_G3_THR  | 60   | MOT_THR_MAX для G3 (%) |
| JRVS_BRK_HOLD| 350  | Утримання тиску перед пульсацією (мс) |
| JRVS_BRK_REL | 400  | Фаза скидання тиску в пульсації (мс) |
| JRVS_BRK_PLS | 80   | Фаза утримання тиску в пульсації (мс) |
