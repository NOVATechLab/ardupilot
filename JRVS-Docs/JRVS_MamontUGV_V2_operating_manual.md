# JRVS Mamont UGV V2 — Інструкція з експлуатації

Амфібійний гідравлічний ровер на платі **JarvisH743** (ArduRover + Lua-скрипт
`JRVS_MamontUGV.lua`, версія V2).

Документ для оператора: підготовка, керування, режими, обслуговування, діагностика.

> ⚠️ **Безпека понад усе.** Перед кожним запуском переконайтесь, що навколо машини
> немає людей. Гідравліка і гребні гвинти небезпечні. Перші тести реле робіть на
> **знеструмленій** силовій частині (див. §9).

---

## 1. Загальний принцип

- **Газом** керує ArduPilot (вихід SERVO1 → регулятор мотора на піні PA0).
- **Lua-скрипт** керує 16 реле: батарея, селектор ходу, гідронасос, клапани тиску
  (гальма), гребні гвинти, кузов, відвал, світло, резерв.
- Машина має **3 режими руху** (перемикач CH6): суходіл / комбі / плавання.
- **Передачі** (G1/G2/G3) обмежують максимальну швидкість через `SERVO1_MAX` і `MOT_THR_MAX`.

Скрипт запускається автоматично при старті плати (вшитий у прошивку, SD-карта не потрібна).

---

## 2. Призначення каналів пульта (SIYI)

| CH | Орган | Функція |
|----|-------|---------|
| CH1 | правий стік ↕ | газ / аварійне гальмо |
| CH2 | лівий стік ↔ | поворот |
| CH3 | — | **вільний** (під QGC) |
| CH4 | — | **вільний** (під QGC) |
| CH5 | тумблер | селектор вперед / реверс |
| CH6 | 3-поз. SC | режим: LAND / COMBI / SWIM |
| CH7 | кнопка T2 | кузов підняти / опустити |
| CH8 | кнопка T3 | відвал-ківш підняти / опустити |
| CH9 | кнопка SD | світло |
| CH10 | кнопка T4 | резерв ± |
| CH11 | тумблер | реле батареї |
| CH12 | 3-поз. | передача G1 / G2 / G3 |

> CH3 і CH4 навмисно не задіяні — щоб не конфліктувати зі стандартними
> призначеннями каналів у QGroundControl. Якщо на вашому пульті органи стоять на
> інших каналах — відредагуйте константи `CH_*` на початку `JRVS_MamontUGV.lua`.

---

## 3. Підготовка та запуск

1. **Огляд.** Перевірте рівень гідрорідини, відсутність витоків, кріплення гвинтів,
   вільність кузова/відвала.
2. **Увімкніть пульт SIYI.** Переконайтесь, що:
   - правий стік (газ) у нейтралі (центр),
   - лівий стік (кермо) у центрі,
   - CH6 (режим) у положенні **LAND** (нижнє),
   - CH5 (селектор) у положенні **вперед**,
   - CH12 (передача) у **G1**.
3. **Подайте живлення на плату.** Дочекайтесь завантаження ArduPilot
   (статус-повідомлення `JRVS: JRVS_MamontUGV V2 ready ...` у наземній станції).
4. **Підключіть батарею:** переведіть **CH11** у верхнє положення і **утримуйте ≥ 1 с**.
   З'явиться `JRVS: Battery relay ON`. Затримка 1 с — захист від випадкового вмикання.
5. Машина готова до руху.

**Вимкнення:** поверніть CH11 у нижнє положення (`Battery relay OFF`), зніміть живлення плати.

---

## 4. Керування на суходолі (режим LAND)

CH6 у нижньому положенні (`JRVS: Mode: LAND`).

### Газ і гальмо (CH1, правий стік вертикально)
- **Вгору (>1510):** газ. ArduPilot розганяє мотор у межах поточної передачі.
- **Центр (1400–1510):** нейтраль (вільний хід).
- **Вниз (<1400):** аварійне гальмо обох сторін — насос вмикається, клапани тиску
  утримують гальмо з антиблокувальною пульсацією.

### Поворот (CH2, лівий стік горизонтально)
- **Вліво (<1380):** підгальмовується ліва сторона → дуга вліво.
- **Вправо (>1620):** підгальмовується права сторона → дуга вправо.
- **Центр:** гальма відпущені.

> Розворот дуговий (газ + одностороннє гальмо). Танковий розворот неможливий —
> один гідропривід на обидві гусениці.
> Аварійне гальмо (CH1 вниз) має пріоритет над поворотом.

### Передачі (CH12)
- G1 — понижена (за замовч. макс. ~20%),
- G2 — середня (~35%),
- G3 — підвищена (~60%).

Перемикання миттєве: `JRVS: Gear N ...`. Значення налаштовуються (див. §7).

### Селектор ходу (CH5)
- **Верх + утримати ≥ 1 с:** реверс (`Selector: reverse`).
- **Низ:** вперед (`Selector: forward`).

> ⚠️ Перемикайте селектор **тільки при нульовому газі** — апаратного блокування немає.

---

## 5. Режим плавання (SWIM)

CH6 у верхньому положенні (`JRVS: Mode: SWIM`).

У цьому режимі **газ і кермо суходільного приводу НЕ діють** — газ SERVO1
автоматично тримається в нейтралі. Рух забезпечують **гребні гвинти** через реле:

| Дія (CH1/CH2) | Гвинти |
|---------------|--------|
| Газ (CH1 вгору) | обидва вперед |
| «Гальмо» (CH1 вниз) | обидва назад (гальмування на плаву) |
| Поворот вліво (CH2) | лівий назад + правий вперед |
| Поворот вправо (CH2) | правий назад + лівий вперед |
| Селектор реверс (CH5) | усі напрямки інвертуються |

> Гвинти одного борту ніколи не вмикаються «вперед» і «назад» одночасно (блокування у скрипті).

---

## 6. Режим комбі (COMBI)

CH6 у середньому положенні (`JRVS: Mode: COMBI`).

Працюють **одночасно** суходільний привід (колеса/гусениці, газ, гальма, поворот)
**і** гребні гвинти. Призначений для входу у воду та виходу на берег.

> При зміні режиму скрипт автоматично скидає виходи попереднього режиму в безпечний
> стан (гвинти OFF, гальма відпущені).

---

## 7. Допоміжні функції (працюють у будь-якому режимі)

| Канал | Орган | Дія |
|-------|-------|-----|
| CH7  | кузов  | вгору / вниз (центр — стоп) |
| CH8  | відвал | вгору / вниз (центр — стоп) |
| CH9  | світло | увімк. / вимк. |
| CH10 | резерв | + / – (центр — стоп) |

- Кузов / відвал / резерв автоматично вмикають **спільний гідронасос** (RELAY3).
- Світло насос не вмикає.
- У кожній парі «вгору/вниз» обидва напрямки взаємно виключені.

---

## 8. Параметри JRVS_* (Mission Planner / QGC)

Скрипт реєструє власні параметри (видно у списку Full Parameter List). Змінюються
без перепрошивки — застосовуються «на льоту».

| Параметр | Дефолт | Опис |
|----------|--------|------|
| JRVS_G1_SVO | 1200 | SERVO1_MAX для G1 (мкс) |
| JRVS_G2_SVO | 1350 | SERVO1_MAX для G2 (мкс) |
| JRVS_G3_SVO | 1600 | SERVO1_MAX для G3 (мкс) |
| JRVS_G1_THR | 20 | MOT_THR_MAX для G1 (%) |
| JRVS_G2_THR | 35 | MOT_THR_MAX для G2 (%) |
| JRVS_G3_THR | 60 | MOT_THR_MAX для G3 (%) |
| JRVS_BRK_HOLD | 350 | утримання тиску перед пульсацією (мс) |
| JRVS_BRK_REL | 400 | фаза скидання тиску в пульсації (мс) |
| JRVS_BRK_PLS | 80 | фаза утримання тиску в пульсації (мс) |

**Як налаштувати швидкість передачі:** збільшіть `JRVS_Gx_SVO` і `JRVS_Gx_THR`
(швидше) або зменшіть (повільніше). Зміна застосується після наступного перемикання
на цю передачу.

**Як налаштувати «жорсткість» гальма:** менший `JRVS_BRK_REL` / більший `JRVS_BRK_PLS`
= сильніше тримання; навпаки — м'якіше, антиблок активніший.

---

## 9. Стендова перевірка реле (без руху машини)

Перед польовими тестами перевірте реле по черзі на **знеструмленій** силовій частині:

1. Подайте живлення лише на плату (силові кола гідравліки/моторів відключені).
2. По черзі задійте кожен канал і переконайтесь, що спрацьовує **правильне** реле
   (звук/індикація реле відповідає таблиці §2 та мапі RELAY у `README.md` плати).
3. Особливо перевірте взаємне виключення пар (гвинти FWD/REV, кузов, відвал, резерв).

---

## 10. Статус-повідомлення (наземна станція)

Скрипт шле текст із префіксом `JRVS:`:

| Повідомлення | Значення |
|--------------|----------|
| `JRVS_MamontUGV V2 ready ...` | скрипт стартував |
| `Battery relay ON / OFF` | стан реле батареї (CH11) |
| `Selector: reverse / forward` | напрямок ходу (CH5) |
| `Gear N ...` | перемкнуто передачу (CH12) |
| `Mode: LAND / COMBI / SWIM` | змінено режим (CH6) |
| `Land: GAS / IDLE / BRAKE / TURN_L / TURN_R ...` | стан суходільного приводу |
| `Brake released` | гальма відпущені |

## 11. Прошивка

```bash
cd /path/to/ardupilot
./waf configure --board JarvisH743
./waf rover
# Результат: build/JarvisH743/bin/ardurover.apj — прошити через Mission Planner / QGC
```

Скрипт `JRVS_MamontUGV.lua` вшивається в прошивку автоматично (ROMFS).

---

## 12. Типові несправності

| Симптом | Імовірна причина / дія |
|---------|------------------------|
| Машина не рухається | не підключена батарея (CH11 не утримано 1 с); перевірте `Battery relay ON` |
| Газ не діє | можливо активний режим SWIM (газ навмисно в нейтралі) — перевірте CH6 |
| Гвинти не крутяться | ви не в SWIM/COMBI; або немає тиску (перевірте гідросистему) |
| Реле спрацьовує не те | звірте призначення каналів пульта зі схемою §2; за потреби правте `CH_*` у скрипті |
| Передача не змінює швидкість | перевірте `JRVS_Gx_SVO/THR`; зміна діє після перемикання на цю передачу |
| Немає повідомлень `JRVS:` | скрипт не стартував — перевірте `SCR_ENABLE=1` і наявність скрипта у прошивці |
